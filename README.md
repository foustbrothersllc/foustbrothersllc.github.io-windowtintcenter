# Window Tint Center Website

Professional window tinting website for Window Tint Center in Greensboro, NC.

## Project Structure

```
window-tint-center/
├── index.html          # Main website
├── images/
│   ├── storefront.jpg  # Hero background
│   └── tinted-car.png  # Tint showcase image
└── README.md
```

## Features

- Sticky header with dynamic hours based on current day
- Fixed parallax hero with storefront background
- Professional tint options showcase (HP Film, Carbon, Ceramic)
- Interactive map with directions
- Mobile responsive design
- Click-to-call functionality

## Deployment

Push to GitHub and connect to Vercel. No build required — static HTML site.

### Custom Domain Setup
1. Go to Vercel project settings → Domains
2. Add your custom domain
3. Update DNS records as directed by Vercel
4. SSL certificate auto-generated
